Code Examples

Basic Initialization

const table = document.getElementById('my-table');
const sourTable = new SourTable(table);
sourTable.initiate();

With Excluded Columns

// Exclude first and third columns (0-based index)
const sourTable = new SourTable(table, [0, 2]);
sourTable.initiate();

Sorting by Data Attributes

// Sort column 2 by data-salary attribute
const sourTable = new SourTable(table, [], { col_2: 'salary' });
sourTable.initiate();

Custom Parsing Functions

// Custom parser for performance column (index 4)
sourTable.addCustomParseFunction(4, (text) => {
    return parseFloat(text.replace(/[%()\-]/g, ""));
});

// Custom parser for date column (index 5)
sourTable.addCustomParseFunction(5, (text) => {
    return Date.parse(text.trim());
});
